# 带外回调分级与证据来源关联

## 适用与触发

用于 SSRF、XXE、JNDI、异步处理和工具副作用候选中出现的 OOB（带外）事件。
同时用于关联断言、工具执行、原始产物和目标身份，防止跨目标或旧轮次证据混用。
仅新增方法文档，不声明本系统已具备签名交付引擎。

## 前提与记录

- 记录目标及范围、应用身份、执行 ID、轮次、构建/配置和 UTC 时间。
- 使用每次尝试唯一的无敏感内容标识，保存发送时间及有效观察窗口。
- 保存监听服务、域名归属、协议、事件 ID 和原始事件。
- 使用批准的回调接收方；禁止在域名标签、URL 或回调体编码目标秘密。
- 缺监听、网络或外连许可时记 blocked，不自动开端口或安装服务。

## 协议证明强度

DNS 事件证明关联名称发生解析，不证明目标取回 HTTP 内容。
HTTP 事件证明某客户端发起请求；归因前不证明该客户端就是目标服务。
TLS 连接、TCP 连接和特定应用协议分别记录，不统一称为执行成功。
HTTP 外连不能直接证明 RCE、敏感文件读取、云凭据获取或账户接管。
执行类结论还需安全标记与实际目标进程/效果的独立关联。
无回调不单独判否：出口限制、异步时延、代理或监听故障都可能阻止观察。

## 基线与对照

1. 检查监听链路可用性，但探测标识与候选标识分开。
2. 正常基线使用独立标识，避免攻击和基线共享事件。
3. 保留确切输入字节；只改变一个 URL、解析开关或身份变量。
4. 排除浏览器、扫描器、链接预览器、DNS 递归解析器和安全设备代访问。
5. 保存事件协议、时间、源信息、路径、标识、重复次数和执行关联。
6. 异步按一次正常处理窗口、最多 5 分钟有界观察；期间处理独立 ready。
7. 到期仍缺关联转 blocked，不提高载荷强度或无限等待。

## 证据来源链

每条断言应关联：断言 → 执行 ID → 原始产物 → 内容哈希 → 目标/身份/时间 → 运行/构建。
原始请求、响应和回调产物保存到批准的本地证据位置。
模型摘录与原件分开，摘录说明范围，不能由模型自报 marker 证明来源。
哈希证明保存内容的一致性，不证明内容真实、捕获时间或归属。
HMAC 是共享密钥认证，不是持公钥即可独立验证的数字签名。
签名也不能使不充分的漏洞证据变充分。
公开摘要可脱敏，原件的敏感内容访问按授权与保留策略处理。

## 目标侧确认条件

- SSRF：证明服务端请求链、目标或资源权限变化，并说明实际影响范围。
- XXE：证明目标解析器触发外部解析；读取或执行影响须另取证。
- 工具调用：真实执行和受保护对象变化，模型叙述/伪工具返回不是证据。
- 仅 DNS 命中可作为 tentative 线索，不写“服务器已下载内容”。
- 同一受控 marker 的外部命中仍需排除基线和采集器自身访问。

## 反证、停止与清理

代理自动访问同一 URL 可解释回调，不代表应用风险已否定；重建独立对照。
监听历史有同名标识时不能复用为本轮证据。
无法追溯原始事件时保持证明缺口，不伪造事件或执行编号。
停止后关闭仅本任务创建的监听，清理测试标记，保留必要审计原件。
不得删除共享采集历史或重置其他任务的浏览器状态。
正式 confirmed 仍需相对起始权限的新增能力、稳定复现及完整 validation。

## 修复与复测

限制最终目标、解析器特性和后台处理权限；不要只过滤显示 URL。
验证 DNS、重定向、地址解析与最终连接阶段的规则一致。
复测采用新标识、正常成功基线和目标版本，保持原历史不可混淆。
