# OPSEC 与对抗检测（Evasion）

> 目标不是"永不触发告警"（不现实），而是**控制噪声、把动作控制在授权范围内、并且能解释每一次动作**。本页给出纪律与检查表，具体 payload 层技术见 skill `av-evasion-skills`。

## 一、三条纪律

1. **最小化**：能只读就不写、能一条命令就不落地工具、能单点验证就不批量扫描。
2. **可解释**：每条命令都要能在报告里说明"为什么这么做"以及预期证据。
3. **可回滚**：创建的文件/账号/规则必须在结束后清理，并记录清理动作。

## 二、噪声来源（常见"自曝"行为）

| 行为 | 触发的检测 |
|---|---|
| 全端口/全网段扫描 | IDS/NetFlow 异常、扫描特征 |
| 落地工具（上传 EXE/大型脚本） | 文件创建、杀软扫描、哈希黑名单 |
| `mimikatz` 特征字符串 | 内存/命令行检测、LSASS 访问告警 |
| `procdump`/`comsvcs.dll` dump LSASS | Sysmon 10（ProcessAccess）、EDR 行为 |
| 大量失败登录 | 账户锁定、喷洒规则告警 |
| 命名明显的 C2 域名/端口（4444/8080/11601） | 出网与流量特征 |
| 修改注册表 Run 键/创建计划任务 | 持久化检测规则 |
| 大流量外传 | DLP、异常连接 |
| 使用真实品牌（钓鱼）被第三方举报 | 域名封禁、客户事件响应 |

## 三、行动前检查表

- [ ] 我有**书面授权**覆盖这项动作（尤其是社工、凭据采集、写操作）？
- [ ] 目标资产在我的**范围内**（不是共享基础设施/第三方）？
- [ ] 这个动作会不会**影响业务**（锁定账号、重启服务、写生产数据）？
- [ ] 有没有**更小**的验证方式（只读 API、错误信息、单请求）？
- [ ] 我是否已记录**时间、主机、命令、预期证据**？
- [ ] 触发告警时的**联系人**是谁（客户的 SOC/IR）？

## 四、对抗检测的原则（不提供具体规避配方）

1. **行为优于签名**：EDR 关注的是进程链、内存行为、采样而非文件哈希 —— 因此"改哈希/加壳"价值有限。
2. **不引入被监控的机制**：如果目标是"证明可达"，就不要真的注入 LSASS；用一个等价但低风险的动作（读 LSA 相关的可读配置）说明可行性并标注"未执行"。
3. **在内存中工作**：优先使用目标自带的解释器与语言（PowerShell/Bash/Python）完成小任务，避免落地可执行文件；但要注意**脚本块日志（4104）**与命令行审计（4688/1）。
4. **控制速率与并发**：低速率、错峰、限制并发数；扫描使用 `--delay`/`-t` 限制。
5. **减少口令尝试**：先确认策略，宁少勿多；必要时用只读接口验证凭据有效性。
6. **日志与遥测的意识**：知道自己在哪留下记录（Sysmon/EDR/网络/云审计），并在报告中说明"预期可见性"。
7. **避免与真实攻击混淆**：不引入与客户威胁情报高度重合的 IoC（如知名 APT 工具），防止误判触发 IR 流程。

## 五、与蓝队协作的"可见性验证"

这是评估中最有价值的产出之一：

1. 与客户约定一份**动作清单**（例如"计划任务创建"、"可疑 PowerShell 编码命令"、"异常出网连接"）。
2. 执行后核对：哪些动作被检测/告警，延迟多久，告警质量如何。
3. 输出"检测覆盖矩阵"（动作 → 数据源 → 是否命中 → 告警质量），而不是只报漏洞。

## 六、云与身份侧的 OPSEC

- 云审计（CloudTrail/Activity Log/Audit Log）记录**每个 API 调用**：`AssumeRole`、`CreateAccessKey`、`GetSecretValue` 都会留痕。
- 连接器/同步工具（如 `roadtools`）会生成大量读取事件 → 控制调用量与时机。
- 避免创建长期凭据（`CreateAccessKey`）；用 `sts:GetCallerIdentity` 之类的只读证明。
- 注意服务端地理与 UA：脚本 UA（python-requests/aws-cli）与浏览器行为不一致会被标记。

## 七、清理清单（结束前）

- [ ] 删除上传的工具与脚本（含 `%TEMP%`/`/tmp` 下的文件）。
- [ ] 删除创建的计划任务、服务、注册表项、用户/账号。
- [ ] 关闭隧道与监听端口，移除路由与转发规则。
- [ ] 移除钓鱼基础设施（域、落地页）并按客户要求处置凭据数据。
- [ ] 汇总"我们创建过的所有东西"清单交给客户。
