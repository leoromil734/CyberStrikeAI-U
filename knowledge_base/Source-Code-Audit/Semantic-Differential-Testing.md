# 跨解析器语义差分与字段生命周期

## 适用与触发

同一攻击者可影响字段被多个组件读取、改写或解释时使用。
包括代理/应用路径、上传分类/消费、URL 校验/连接、缓存/身份和错误/重试分支。
仅有不同错误信息不足；关注安全决策使用值与危险消费者使用值是否一致。

## 前提与版本

记录各组件的实现、版本、配置、协议、构建和当前部署映射。
固定入口、身份、对象、正常客户端及原始输入字节。
畸形 framing、崩溃、耗尽和延迟体测试仅适用于另行批准的可恢复隔离环境。
本方法不授权联网 fuzz、安装 Hypothesis/Hurl 或运行陌生代码。

## 变换图与安全不变量

画出：原始字节 → 传输解析 → 中间件表示 → 安全决策 → 再变换 → 最终消费者。
为每条边记录输入/输出类型、组件、变换、错误处理和是否仍保留旧值。
为共享字段记录所有已找到的写者、读者、别名与所有者。
声明不变量，例如“校验路径与最终打开路径必须处于相同允许目录”。
校验表示 A 与消费表示 B 的差异需落到对象、权限或执行效果。
区别正常路径、错误路径、重试、内部跳转、子请求、缓存及后台 worker。
字段从文件名变 URL、类型变 handler、用户值变配置默认值均需要重新核查。

## 聚焦差分矩阵

- 编码：解码次数、Unicode、大小写、替换字符，仅选实际组件支持的轴。
- 结构：重复字段、空值、列表合并、first/last-wins 与类型转换。
- 路径：段级匹配、前缀相邻目录、斜杠、绝对路径和规范化位置。
- URL：scheme、userinfo、origin、主机解析、重定向与最终地址。
- 生命周期：异常后是否继续、旧身份/元数据是否被复制到新任务。
- 命名空间：本地、缓存、workspace、私有/公共 registry 的回退顺序。
不建立全笛卡尔积；每次只改变一个有证据支持的表示轴。

## 最小验证流程

1. 建立正常成功基线，确认 handler 与部署代码对齐。
2. 构造只差一个表示的输入对，保留发送前原始字节。
3. 记录控制点看到的值 A、消费者实际看到的值 B 与中间变换。
4. 使用自有对象、合成标记或可回滚效果证明边界变化。
5. 重复正常/异常对照，排除缓存、限流、客户端自动规范化和错误页。
6. 缩减反例到最少字段，保存条件和支持/不支持的版本。
7. 只有目标侧新增权限和真实效果成立才 confirmed；本地解析差异先记 tentative。

## 离线生成器与工具

纯函数差分可使用已有本地测试设施，限制大小、样例数和运行时间。
输入生成与网络/进程传输分离；连接真实目标后性质已经改变。
Hypothesis/Hurl 是可选外部依赖，无专用封装不声明为注册工具。
高层 HTTP 客户端可能规范化输入；使用已批准原始捕获验证实际发送内容。
工具输出中的日志显示形式不能替代最终消费者状态。

## 反证与证明缺口

两解析器不同，但没有安全决策处于二者之间，不证明漏洞。
异常语法被最终消费者安全拒绝，只否定当前假设。
绕过边缘规则但应用同样拒绝，不证明业务越权。
无法观察 A/B、找不到消费者或不能对齐部署，明确 proof gap。
动态加载/隐藏调用可能漏查，静态搜索结果不能声称所有路径安全。
既有 CORS、安全头及低价值排除继续优先。

## 停止、清理与修复

同组合三次无新证据换路；健康异常、未批准副作用或无法恢复即停止。
移除仅本任务生成的测试对象，保存读回和清理证据。
修复应在实际消费前基于规范化后的单一表示决策，拒绝歧义和失败开放。
共享 helper 的兄弟调用、错误/异步分支与正常行为均加入回归测试。
