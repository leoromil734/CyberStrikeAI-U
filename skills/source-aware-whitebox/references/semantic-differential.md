# 校验值与消费值的语义差分

## 触发

相同输入经过代理/路由/校验/解码/文件/解释器/后台任务多次读取时使用。

## 窄链流程

1. 固定组件版本、部署、入口和正常基线；声明安全不变量。
2. 画出字节 → 解析 → 安全决策 → 再变换 → 最终效果，记录每边类型和错误处理。
3. 列共享字段所有已发现读写者，包括正常、错误、重试、内部跳转和异步路径。
4. 从实际栈选择一个轴：编码/重复字段/路径/URL/类型/生命周期，不做全组合喷测。
5. 捕获控制点看到的 A 与消费者看到的 B，并证明中间变换和实际权限效果。
6. 用自有对象/合成标记重复正常和反例，缩减输入，记录版本适用范围。
7. 本地差异是候选；动态新增能力才 confirmed。无法观察 A/B 或部署不齐保留 proof gap。

## 工具与边界

Hypothesis/Hurl 是可选依赖，不声明已注册/已安装，也不自动安装。
只读本地纯函数生成器与网络/进程传输分离；联网 fuzz 需独立授权。
畸形 framing、崩溃/耗尽仅在另批可恢复隔离环境，本流程不默认执行。
日志表示不同但消费者权限一致是反例；curl 自动规范化要核查实际发送字节。

## 停止与修复

同组合三次无新证据换路；异常副作用停止并清理本任务对象。
修复使用最终规范表示在消费前统一判权，拒绝歧义与失败开放；覆盖兄弟调用和合法行为。
