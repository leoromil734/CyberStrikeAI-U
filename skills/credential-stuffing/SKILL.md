# 有界弱口令验证

范围内每个已确认且支持密码的认证入口做一轮，命中或预算耗尽即停。侦察角色只识别入口与前提，交接给验证角色；不能把“不做大规模爆破”解释为“不做简单弱口令尝试”。

## 入口与身份

- 覆盖 Web/管理后台、SSH、数据库及 SMTP/IMAP/POP3，不因非 HTTP、部署在 Hetzner 等托管商而跳过。
- 先确认协议、认证方式、范围、已有失败次数和锁定策略。SSH 仅公钥认证、SMTP 不提供 AUTH 等须有协议证据才记 N/A；未做认证能力探测不能记 N/A。
- 身份只用用户提供、范围内 JS/页面/响应已有的演示或测试账号、受控账号，以及产品文档明确的默认用户名。精简用户名字典只帮助筛选已有/默认身份，不用来枚举陌生账号或手机号。
- 缺身份记 `blocked`，原因写“缺身份，未尝试”，继续独立可测入口。明确范围或策略排除的入口记录理由，不发送认证请求。

## 统一预算

先登记预算再执行，用户更严格的限制优先：

- 每账号最多 **8 次**；同一认证域/账号跨 Web、SSH、数据库、邮件累计，不通过换接口或换 IP 重置。
- 每入口最多 **5 个账号、40 个候选组合、5 分钟**，三者任一先到即停。
- 并发 **1**，两次认证开始时间间隔至少 **3 秒**；已知锁定阈值更低时继续缩小预算。
- 先按产品挑最多 3 组默认对/空密码，再从精简口令字典挑剩余高价值候选；默认对和失败对照都计入 8/40 次，不另开一轮。
- 简单候选可用 `123456`、`12345678`、`111111`、`888888`、`admin123` 或已知用户名自身。手机号自身/后 6 位仅用于已给定测试身份，仍计入总上限。
- 禁止把用户名字典与密码字典做全量笛卡尔积。先生成满足预算的候选对文件，执行前核对 `wc -l`，不直接把完整的 `-L` 与 `-P` 同时交给 Hydra。
- 标准密码字典中的 3000 行是备选池，不是允许在线尝试 3000 次；精简档只用于明确的快速首轮。同一组合因网络错误最多重试一次，实际认证请求仍计入预算；连续网络/协议错误 3 次换路或 blocked，不把正常拒绝响应误当工具故障。

## 停止与验证

命中、验证码/滑块、MFA、锁定、429、尝试过多、服务异常即停止该认证域；不 OCR、不绕挑战、不换 IP 续试。因保护机制或预算停止记 `blocked` 及已测子集，不把剩余空间写为已排除。

SSH 成功只做 `id` 等只读身份确认；数据库只查当前用户/权限；邮件只做认证/能力确认，不读取信箱、不发信。失败对照必须在剩余预算内完成。确认跨越匿名→认证边界且具有实际权限影响才 `record_vulnerability`，字典猜测类型写“弱口令”；只有真实凭据复用证据时才写“撞库”。登录 HTML、端口开放或工具声称成功不是认证证据。

每入口保存 `target, protocol, identity_source, dictionary_path/hash, planned_pairs, attempted_pairs, elapsed_seconds, stop_reason, evidence`；秘密按项目证据权限保存，进度摘要不打印密码。完整轮次内所选候选全部拒绝时记有条件负结果；禁止据此宣称不存在弱口令。

## 分档字典

常规候选池用 `/opt/wordlists/cyberstrike-standard`，快速首轮可选原精简档。位置、来源、条数与复现安装见 `references/lite-wordlists.md`。缺字典时记 blocked 并用已知产品默认对作替代，不自动下载 rockyou/全集；字典扩容不放大认证预算。
