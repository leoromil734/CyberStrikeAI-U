# 分档弱口令验证

范围内每个已确认且支持密码的认证入口先做轻量首轮；高价值认证面在满足前提时进入深度档，并优先使用根据已知信息生成的针对性字典。侦察角色只识别入口与前提，交接给验证角色；不能把“不做大规模爆破”解释为“不做简单弱口令尝试”，也不能把“有界”解释成“永远只用 40 个组合”。

## 入口与身份

- 覆盖 Web/管理后台、SSH、数据库及 SMTP/IMAP/POP3，不因非 HTTP、部署在 Hetzner 等托管商而跳过。
- 先确认协议、认证方式、范围、已有失败次数和锁定策略。SSH 仅公钥认证、SMTP 不提供 AUTH 等须有协议证据才记 N/A；未做认证能力探测不能记 N/A。
- 身份只用用户提供、范围内 JS/页面/响应已有的演示或测试账号、受控账号，以及产品文档明确的默认用户名。精简用户名字典只帮助筛选已有/默认身份，不用来枚举陌生账号或手机号。
- 缺身份记 `blocked`，原因写“缺身份，未尝试”，继续独立可测入口。明确范围或策略排除的入口记录理由，不发送认证请求。

## 分档预算

先登记预算再执行，用户更严格的限制优先：

**轻量首轮（默认起步，锁定策略未知时）**
- 每账号最多 **8 次**；同一认证域/账号跨 Web、SSH、数据库、邮件累计，不通过换接口或换 IP 重置。
- 每入口最多 **5 个账号、40 个候选组合、5 分钟**，三者任一先到即停。
- 并发 **1**，两次认证开始时间间隔至少 **3 秒**；已知锁定阈值更低时继续缩小预算。
- 先按产品挑最多 3 组默认对/空密码，再从针对性字典（见下）挑剩余高价值候选；默认对和失败对照都计入 8/40 次，不另开一轮。

**深度档（第二轮；满足全部前提才进入）**
- 前提：轻量首轮已执行并记录；未观察到锁定、验证码/滑块、MFA、429 或异常；入口属于高价值认证面（管理/后台/邮箱/品牌账号登录，或已有邮箱前缀、人名等身份线索）。
- 预算：每账号最多 **30 次**；每入口最多 **10 个账号、300 个候选组合、20 分钟**，三者任一先到即停；并发 ≤ **4**，每次尝试间隔 ≥ **1 秒**（hydra `-t 4 -W 1`；`-c` 会强制单线程，仅用于更保守场景）。
- 候选来源：优先针对性字典的前部条目，其次通用档高价值子集；仍禁止把用户名字典与密码字典做全量笛卡尔积或引入 rockyou/全集替代纪律。
- 命中、出现保护机制、或按锁定证据缩小的预算用尽即停；深度档不是“无限爆破”，不因换接口或换 IP 重置预算。

**两档共同纪律**
- 简单候选可用 `123456`、`12345678`、`111111`、`888888`、`admin123` 或已知用户名自身。手机号自身/后 6 位仅用于已给定测试身份，仍计入总上限。
- 标准密码字典中的 3000 行是备选池，不是允许在线尝试 3000 次；同一组合因网络错误最多重试一次，实际认证请求仍计入预算；连续网络/协议错误 3 次换路或 blocked，不把正常拒绝响应误当工具故障。

## 针对性字典（优先于通用字典）

通用字典命中率低；先用已掌握的情报生成一份小型高概率字典，再按预算递进使用：
`python3 /opt/CyberStrikeAI-U/skills/credential-stuffing/scripts/wordlist_gen.py`

1. 收集基词（有多少用多少）：
   - 品牌/组织名及变体（连写、分词、缩写，如 `libertysilver` / `liberty silver` / `ls`）
   - 页面、证书、JS、邮件、招聘页中出现的人名与邮箱前缀（`Caroline Eking`、`caroline.eking`）
   - 站点关键产品词（`myaccount`、`webmail`、`cpanel`、`vpn`）与年份（前后 2-3 年）
   - 已知用户名本身、用户名大小写变体
2. 生成（确定性输出，便于记录与复现）：
   ```bash
   python3 /opt/CyberStrikeAI-U/skills/credential-stuffing/scripts/wordlist_gen.py \
     --base libertysilver --base "liberty silver" \
     --name "Caroline Eking" --email-prefix caroline.eking \
     --domain libertysilver.se --product myaccount \
     --year-from 2023 --year-to 2026 --max 1200 \
     --out "$PWD/wordlist-libertysilver.txt"
   ```
3. 记录与使用：保存输出路径、`sha256sum`、`wc -l` 与生成参数；前 ~40 条按预算做首轮，深度档按序递进；命中的候选与失败对照都计入预算。
4. WordPress 登录用 `wpscan --passwords <生成的字典> --usernames <已知用户>`；其他协议用 hydra `-P <生成的字典>`，或与产品默认对合并为有界候选对文件（执行前 `wc -l` 核对）。

## 停止与验证

命中、验证码/滑块、MFA、锁定、429、尝试过多、服务异常即停止该认证域；不 OCR、不绕挑战、不换 IP 续试。因保护机制或预算停止记 `blocked` 及已测子集，不把剩余空间写为已排除。

SSH 成功只做 `id` 等只读身份确认；数据库只查当前用户/权限；邮件只做认证/能力确认，不读取信箱、不发信。失败对照必须在剩余预算内完成。确认跨越匿名→认证边界且具有实际权限影响才 `record_vulnerability`，字典猜测类型写“弱口令”；只有真实凭据复用证据时才写“撞库”。登录 HTML、端口开放或工具声称成功不是认证证据。

每入口保存 `target, protocol, identity_source, dictionary_path/hash, planned_pairs, attempted_pairs, elapsed_seconds, stop_reason, evidence`；秘密按项目证据权限保存，进度摘要不打印密码。完整轮次内所选候选全部拒绝时记有条件负结果；禁止据此宣称不存在弱口令。

## 字典与生成器

常规候选池用 `/opt/wordlists/cyberstrike-standard`，快速首轮可选原精简档，针对性字典用上文生成器产出。位置、来源、条数与复现安装见 `references/lite-wordlists.md`。缺字典时记 blocked 并用已知产品默认对作替代，不自动下载 rockyou/全集；字典扩容不放大认证预算。
