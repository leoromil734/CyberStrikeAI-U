# 范围内拓展假设

本 Skill 的 “unlimited” 只表示**不被固定漏洞清单限制思路**，绝不表示授权范围无限、测试时间无限或可以忽略停止条件。

## 使用条件

仅在以下情况加载：

- Standard/Deep 已建立攻击面，但高价值目标没有可验证候选。
- 现有候选连续得到负结果，需要换攻击域或能力原语。
- 多个低影响事实可能组成一条新的边界突破，但连接关系尚未证明。

## 搜索方法

1. 从黑板提取已证实能力，例如 read、write、request、render、sign、impersonate、schedule。
2. 写出目标能力及缺失前提，不从漏洞名称反推结论。
3. 生成少量跨域假设，并按可证伪性、影响和验证成本排序。
4. 一次验证一条连接边；前一段未证实时，不继续扩展后续链。
5. 新证据写入，负结果进入 Do-Not-Repeat；三次同类无新增证据后换域。

## 硬边界

资产、账号、网段、协议、数据和操作强度始终受当前 scope/ROE 限制。不能为了补链使用范围外凭据或第三方资产，不能把“理论可组合”写成 confirmed。
