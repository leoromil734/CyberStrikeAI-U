# Web 注入差分

只在已确认可控输入进入对应解析上下文时使用本页。每次测试先保存正常请求，再改变一个输入变量。

| 上下文 | 初始探针 | 正证据 | 常见误报 |
|---|---|---|---|
| SQL/NoSQL 查询 | 引号、布尔相反条件、低风险时间差分 | 可重复的内容/记录/时间差分，或受控数据读取 | 通用 500、网络抖动、缓存 |
| 操作系统命令 | 安全回显、短时间差分、唯一 OOB 标记 | 命令输出、稳定时差或可关联 OOB | 应用延迟、DNS 预取 |
| 服务端模板 | 无副作用算术表达式 | 服务端计算结果且不同于客户端渲染 | 前端模板、原样反射 |
| XSS/DOM | 与实际 HTML/属性/JS/URL 上下文匹配的安全标记 | 在目标执行上下文触发，能证明来源与 sink | 仅反射、浏览器扩展、CSP 阻断 |
| XML/解析器 | 外部实体或解析错误的低影响对照 | 文件片段、唯一 OOB 或解析行为差分 | 网关拒绝、统一错误页 |

## 验证顺序

1. 确认输入是否原样、编码后或结构化进入响应/查询/模板。
2. 选择与上下文一致的最小探针，不同时尝试多个语法族。
3. 正反条件至少各复测一次；时间差分使用多组基线排除抖动。
4. OOB 事件必须含唯一关联标识和时间窗口。
5. 只在影响成立后扩大到最小必要数据或能力证明。

SQLi 可用 sqlmap 缩小参数，但工具输出仍需目标侧差分；XSS 可用 dalfox 找上下文，但“payload reflected”不等于执行。
