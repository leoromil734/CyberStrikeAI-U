# 有界撞库

管理面、数据库、中间件、默认口、nacos、jenkins 再读本页后半「管理面 / 中间件默认口」。C 端登录、撞库、手机号口令仍只做上面的有界撞库。

身份只用任务给定、JS/页面/响应、注册回显里已经出现的手机号、用户名、邮箱。禁止生成号段。

每个身份最多 8 个口令：空密码、`123456`、`12345678`、`111111`、`888888`、`admin123`、手机号本身与后 6 位、用户名本身。单接口最多 5 个身份；用户给了名单时最多 20 个。命中即停。

验证码、滑块、锁定、429 立刻停，记负结果。不 OCR，不绕滑块。

进号才 `record_vulnerability`，类型写 `撞库`，并保留失败对照与成功会话。没进号不写漏洞。进号后还要证明权限有影响（能读他人数据、改配置或执行）；只有空壳登录页不算。

## 管理面 / 中间件默认口

和 C 端撞库分开。暴露的管理面、数据库、中间件（nacos、jenkins、redis、tomcat manager 一类）做一次产品默认口，不要等「登录、撞库」关键词。

每个入口最多 3 组，命中即停：空密码、`admin`/`admin`、该产品文档里的默认对（如 `nacos`/`nacos`）。验证码、锁定、429 立刻停。禁止全号段和无限试密。

进了能读数据、改配置或执行的权限才记漏洞。只打开登录 HTML、或进去后没有这些权限，记负结果。
