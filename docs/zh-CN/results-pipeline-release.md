# 结果流水线发布与回滚

## 实施范围

- 资产默认继承对话项目，支持多项目链接、IP/来源观测和并发原子去重；保留旧主项目与所有者边界。
- 每次执行自动留元数据，原件落文件；离线结构化库存、来源真实新增量、有界证据读取与候选发现分层。
- 新绑定项目批量任务默认全面评估；真实端点/JS工作组与来源完整性参与门禁，拒绝、有缺口交付和历史任务/手动续跑分开。
- 正式漏洞的原有 POC 与独立安全边界验证保持不变；新增报告 finding ID/条数一致性校验和紧凑修复反馈。
- JS 心跳、全局预算、分批、取消/超时最后清单及部分结果；离线 URL/JS/map 候选整理。
- 参数类型/整数/范围/枚举校验、共享工具进程并发预算与只运行安全帮助入口的工具预检。

本次不实施模型通道熔断/恢复，不开通受控邮箱或自动补齐双账号；身份由用户在原任务提供。没有执行目标扫描或 POC，也没有改写历史漏洞。

## 验证方式

Windows 的 Go 1.25/GCC 16 组合无法正确构建本仓库 SQLite CGO 模块；完整 Go 回归与编译使用隔离 Linux 源码。Python 脚本必须兼容服务器 Python 3.10。安全 shell 测试同时检查普通用户的 sudo 拒绝和 root/已授权无密码规则的快速成功，而非假设 sudo 在所有环境都必须失败。

`cmd/validate-results` 仅接受 `csai_validation_*` PostgreSQL 数据库，并在迁移前检查真实 current_database。对生产一致性备份的隔离副本执行两次迁移、64 路同实体/多 IP/双项目写入、原件库存幂等与跨项目拒绝检查；它不启动扫描或验证 POC。

## 发布文件

服务器暂存目录约定：`/opt/csai-staging/results-pipeline-20261002`。

- `source/`：隔离验证源码。
- `bin/cyberstrike-ai`、`bin/tool-doctor`、`bin/validate-results`：编译产物。
- `logs/`：回归和工具兼容性报告。
- `backups/`：权限受限的运行文件和 PostgreSQL 一致性备份。
- `release/`：准备后产生的凭据保留发布覆盖层；不得公开或上传到仓库，FOFA 自定义脚本可能含现有凭据。

运行 `python3 scripts/stage_results_release.py --stage <暂存目录> --source <源码目录>` 只准备发布，不停止/重启服务、不写生产文件。

工具覆盖只涉及 `jsapiscan.yaml` 和 FOFA 的 fields 输出；保留部署 command、args、enabled、已有默认值与凭据。其他 7 份已有部署覆盖不替换。FOFA 的实际自定义实现与已知包络不匹配时准备失败，不能用默认模板覆盖现有密钥或派发逻辑。`config.yaml` 不覆盖，模型通道和 systemd/JS 非 root 沙箱配置不变。

## 激活条件

本次生产任务活动期间仅暂存，不能激活。以后由管理员先阻止新提交与自动调度，确认全局维护窗口，并提供现有、覆盖全用户任务的管理员令牌（环境变量 `CSAI_ADMIN_BEARER`，不打印或保存到源码）。

显式调用发布脚本的 `--activate --maintenance-confirmed` 才可能激活。脚本要求：

1. 全局 running/queued 工具为零。
2. running 批量执行器为零。
3. 过去 15 分钟没有工具启动记录。
4. 现有 `/api/agent-loop/tasks` 返回空的内存任务列表；请求失败、令牌缺失或响应形状异常均拒绝。
5. 原有部署覆盖重新合并，激活前重新备份并再次检查空闲。

这些检查不能替代管理员维护窗口，尤其不能用只看本人任务的令牌判定全系统空闲。脚本没有创建登录会话、邮箱或目标账号，也没有启用自动等待后重启或定时激活。

## 回滚

激活前保留二进制、当前 tools/scripts/skills/web 和配置的运行备份，同时保存数据库备份。启动失败时脚本恢复原运行文件并启动旧版本；配置未被部署覆盖，因此自动回滚不覆盖配置。新增 Go 源文件可留在目录中，但旧二进制不会使用它们。

数据库迁移是新增表/索引及旧资产关联补齐，不改写历史任务状态/漏洞/正文。自动回滚不恢复旧数据库快照、不删除新增表；强行恢复旧快照会丢失备份之后的任务记录，必须另行在维护窗口审阅并授权。

## 已知边界

- 并发预算限制工具进程，不是假定能统计或限制任意脚本内部的 HTTP 请求数。目标列表文件和通用脚本内部的目标不可被可靠识别时只用全局/工具预算。
- 未知 scope 的库存与自动导入的 inactive 资产是观察候选，不等于新扫描许可。
- 原件大小、解析字节/条数、返回页和处理时间均有上限；超过上限明确为 partial/gap，不能假称覆盖完整。
- 自动最小证据始终 unverified。正式保存仍需要完整可复现 POC/实际输出及独立安全边界。
- 历史结果不会重新标记为已验证；新门禁不虚构旧任务的证明。
