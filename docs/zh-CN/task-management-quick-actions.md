# 任务管理：模型状态与快捷操作

## 模型测试状态

任务管理的“发起任务”和对话左侧的模型选择器读取系统设置中已保存的模型测试记录，不会因打开选择器而再次调用模型。

- **可用 / 失败**：最近一次测试结果。
- **配置已更改，需重测**：记录对应旧配置，不能代表当前配置可用。
- **未测试**：没有已保存记录。
- **测试记录加载失败**：记录服务暂不可用，与“未测试”不同。

选项显示首 token 时间；选中项详情或选项提示显示测试时间及安全错误摘要。“跟随默认通道”会展示当前默认模型对应的结果。模型失败或未测试不会自动禁用选择。

## 集合详情

状态摘要可直接点击筛选，筛选栏也提供全部、待恢复、拒绝、失败、暂停、待执行及其他实际存在的状态。搜索目标、原任务内容或错误可与状态筛选叠加。自动刷新保留筛选条件和已展开的运行详情。

例如“已处理 3 / 16 项，1 项拒绝、2 项失败、13 项待恢复”，点击“13 项待恢复”只显示这 13 项。处理进度不是成功率；历史队列结果与原会话后续运行分开显示。

## 三种执行操作

- **继续执行**：使用现有队列单任务执行接口，启动待执行项或恢复暂停项。保留现有确认提示。
- **发送“继续”**：向原会话追加字面消息 `继续`，保留会话历史、原模型及项目，沿用队列角色和代理模式，并保留更严格的历史评估要求。仅收到服务端启动确认后显示成功。不能用于没有原会话或仍在执行的任务。
- **重新执行**：重新开始该任务，可能重置该子任务结果并创建新会话，需二次确认。

“对筛选结果发送继续”在确认数量与模型消耗后，向匹配的空闲会话逐个发起继续请求。自动跳过活跃、无会话、已成功交付及未知结果项，同一会话只发送一次；失败逐项提示，不自动重试。这是独立会话的手动续跑，不是按队列并发数重新调度整轮任务。

未收到启动确认不代表后台一定没有启动；先查看原会话，再决定是否重试，避免重复提交。

## 复制原始输入

“复制原始输入”读取原会话最早的用户消息，完整保留目标、换行和文字，不复制截断标题或任务预览。只有尚未关联会话的任务才使用当前任务输入；关联会话读取失败时会明确报错，不以改过的任务文案代替原文。剪贴板支持非 HTTPS 环境的兼容回退。

继续操作需要任务和对话写权限；原文读取需要任务和对话读权限，并分别检查资源访问范围。
